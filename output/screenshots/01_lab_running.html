headscaletest-poc — Lab running

Docker Compose stack with 9 containers (headscale + 4 sidecars + 4 services/personas). Headscale acts as the self-hosted control plane on host port 18080 (mapped from container 8080, since geodesic-traefik already owned 8080 on this host). Each sidecar is on its own isolated bridge. Each service+sidecar pair shares a network namespace so the only cross-container path is the WireGuard overlay.
